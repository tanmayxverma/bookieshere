# Typography Specification & Style Guide

## Project: BOOKIE Design System
**Target Screen Reference:** BOOKIE - Premium Web Experience

### Core Directive: The Ruling Main Font

The primary ruling font established across the headline hierarchy in BOOKIE - Premium Web Experience is **Syne** (specifically Syne 800/900 ExtraBold & Black).

Moving forward, **Syne** is designated as the **Ruling Main Font** across the entire BOOKIE platform for:
- All primary hero headlines (H1)
- Major section headers (H2)
- High-impact display numbers and metrics
- Brand identity anchors and key campaign banners

### Complete Multi-Font Typographic Hierarchy

| Role | Font Family | Weights | Applied To | Design Purpose |
| :--- | :--- | :--- | :--- | :--- |
| **Ruling Main Font (Display & Headings)** | **Syne** | 800, 900 | Hero headlines, primary page titles, bold visual hooks | High-impact geometric weight, cutting-edge tech aura, bold presence |
| **Secondary & UI Headings** | **Plus Jakarta Sans** | 700, 800 | Section headers, card titles, modal titles | Sharp, authoritative, modern neo-grotesque readability |
| **Editorial & Human Voice** | **Newsreader** (Serif) | 400, 400 Italic | Subheaders, student quotes, relatable hostel wisdom | Warm, thoughtful, literary contrast |
| **Technical & Telemetry Data** | **JetBrains Mono** | 500, 700 | Countdown timers, coupon codes, keyboard badges, test codes | Crisp, engineering precision for data and status tags |
| **Universal Body Copy** | **Inter** | 400, 500 | Explanatory paragraphs, feature lists, meta descriptions | Neutral, high-legibility scanning with zero visual fatigue |
